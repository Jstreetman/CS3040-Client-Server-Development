# CS3040-Client-Server-Development

### How do you write programs that are maintainable, readable, and adaptable?

When I write programs, I try to keep my code organized and easy to understand so that I can make changes without having to rewrite everything. One example of this was the CRUD Python module I developed in Project One. Instead of writing separate database connections throughout my dashboard in Project Two, I was able to reuse the same module to retrieve animal records from MongoDB. This saved me time and made the project easier to manage because I could focus more on building the dashboard itself. I also learned how useful it is to separate different parts of an application. In the future, I could use a similar CRUD module for other projects that need to store, retrieve, or manage information in a database.

### How do you approach a problem as a computer scientist?

When approaching a programming problem, I usually start by understanding what needs to be accomplished before figuring out how to implement it. For the Grazioso Salvare project, I had to consider how the organization would use the dashboard to identify animals for different rescue training categories. I approached this by working through the database requirements first and then connecting those results to the dashboard's filters, table, chart, and map. Compared to some of my previous assignments, this project required me to think more about how different components work together rather than focusing on one piece of code. Moving forward, I would continue breaking larger problems into smaller tasks, testing each part as I go, and making sure the final application meets the client's needs.

### What do computer scientists do, and why does it matter?

I believe computer scientists do more than just write code. We use technology to solve problems and make everyday tasks easier for people and organizations. This project helped me understand that better because the dashboard I created could help Grazioso Salvare search through animal records without having to review everything manually. By allowing users to filter animals based on rescue categories and view the results through charts and maps, the organization could make better decisions about which animals might be suitable for training. To me, that is one of the most rewarding parts of software development. Being able to take a problem someone is facing and create something that makes their work more efficient is what makes this field important.
